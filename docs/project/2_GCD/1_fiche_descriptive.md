# Fiche descriptive

- **Titre** : Dying Star
- **Site internet** : https://dyingstar-game.com/
- **Elevator pitch** : MMO futuriste sur un univers unis (serveur unifié) différents gameplay possibles (minage, transport, achat/vente…). Le joueur incarne un humain dans un univers dynamique en constante évolution. Le joueur choisit parmi les gameplay offerts ce qu’il souhaite faire. Cela se passe dans l’univers, comprenant des planètes, des systèmes stellaires.
- **Genre** : First Person View, Immersive Sim, Jeux Systemique
- **Nombre de joueurs** : max 10000 simultané
- **Public visé** : hard-core gamers, ceux qui aiment la SF
- **Plateforme cible** : Mac, Linux, Windows
- **Marché cible** : Monde entier
- **Technologies** :
  - **Moteur** : Godot
  - **Serveur** : Horizon / Godot
  - **Audio** : Wwise
  - **3D** : Blender
  - **Unique Selling Points** : Une aventure immersive futuriste, dans un monde ouvert et dynamique (systèmes planétaires) qui tient place sur un serveur unique. L’univers hard SF est omniprésent. L’espace de jeu est possible en solo ou à plusieurs via des gameplays divers et à son aspect social.
