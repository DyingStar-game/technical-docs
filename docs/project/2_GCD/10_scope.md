# Scope

Le scope est un scénario / boucle de gameplay du jeu afin d’être jouable un minimum.


MVP :
- une zone de la planète
- village minier (carrière ouverte)
- ville (raffinage)
- gameplays : minage + transport
- un véhicule de transport de matériel
- caisses de transport, système d’inventaire

Scénario possible:

Le  joueur débutant prend une mission ou il doit récupérer un équipement, puis aller casser un cailloux et le récolter (système d’inventaire). Il doit ensuite le charger dans un véhicule (au village minier) et le transporter pour aller le vendre dans la ville. Possibilité pour les joueurs de se grouper et de partager les missions.
