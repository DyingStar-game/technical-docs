# Sol de iodure de fer

## Description
Le Iodure de fer est un melange de fer et iode. 
Elle se depose en surface de terrein ayant une forte concentration de ces minereaux. 

## Coposition
Iode (I)
Fer (Fe)

## Condition
Presence d'Iode 
Presence de Fer
