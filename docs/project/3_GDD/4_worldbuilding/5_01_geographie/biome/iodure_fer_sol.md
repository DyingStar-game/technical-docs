# Sol de iodure de fer

## Description

L'iodure de fer est un mélange de fer et d'iode. Il se dépose à la surface des terrains ayant une forte concentration de ces minerais.

## Composition

- Iode (I)
- Fer (Fe)

## Condition

- Présence d'iode
- Présence de fer
