# Désert sablonneux d'ilménite

## Description
Région hyper-aride dominée par l'accumulation de cristaux noir d'oxyde de fer et de titane. 

## Coposition
 FeIITiO3 

## Condition
Presence de titane. 
Presence de fer. 
Presence d'oxygene.
