# Désert sablonneux d'ilménite

## Description

Région hyper-aride dominée par l'accumulation de cristaux noirs d'oxyde de fer et de titane.

## Composition

Ilménite (FeTiO₃)

## Condition

- Présence de titane
- Présence de fer
- Présence d'oxygène
