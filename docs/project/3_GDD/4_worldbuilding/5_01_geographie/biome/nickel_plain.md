# Plaine de nickel

## Description
Étendue ayant une majeur de quantité de nickel dans le sol. 

## Coposition
Nickel (Ni)

## Illustration
![Plaine de nickel](/img/biome/rocky_desert_corindon_cameleon_laiteux.jpg)


## Composants

### Dendrites de cuivre 

## Description
Les structures de dentrites peuvent monter de 2m à 3m sur gravité de 1g
Sur une lune elle peuvent monter bien plus haut.
C'est des structures très fragiles. 

## Composition
cuivre

## Condition
Presence de cuivre.
Très fragile (Seul les buissons existeront à la surface d'une lune.)
