# Plaine de Chlorure de Calcium

## Description
Mélange de chlorure de calcium dissout dans l'eau de couleur bronze ou d'un brun doré, sous forme de liquide épais et sirupeux.

## Composition
Fluore + Calcium (CaCl2, H2O)

## Condition
chlorure (Ca)
calcium (Cl)
Eau (H2O)
