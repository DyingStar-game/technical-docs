# Plaine de Chlorure calcium

## Description
Mélange de chlorure de calcium dissous dans l'eau. 
Couleur bronze ou brun doré
Liquide épais et sirupeux

## Coposition
Chlorure + Calcium (CaCl2, H2O)

## Condition
chlorure (Ca)
calcium (Cl)
Eau (H2O)
