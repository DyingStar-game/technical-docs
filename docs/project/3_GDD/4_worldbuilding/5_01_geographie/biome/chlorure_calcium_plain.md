# Plaine de Chlorure de calcium

## Description

Mélange de chlorure de calcium dissous dans l'eau, de couleur bronze ou brun doré, formant un liquide épais et sirupeux.

## Composition

Chlorure + calcium (CaCl₂, H₂O)

## Condition

- Chlorure (Cl)
- Calcium (Ca)
- Eau (H₂O)
