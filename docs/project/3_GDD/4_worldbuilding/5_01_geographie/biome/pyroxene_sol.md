# Sol de Pyroxène

## Description

Le pyroxène est un minéral très commun, souvent magmatique.

## Composition

Pyroxène : XY(SiO₃)₂, où X et Y sont des cations (ions ayant perdu des électrons).

## Condition

- Présence de silicium
- Présence d'oxygène
