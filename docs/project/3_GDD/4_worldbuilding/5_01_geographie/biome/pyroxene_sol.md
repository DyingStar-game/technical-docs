# Sol de Pyroxene

## Description
Le Pyroxene est un minéraux très comun souvent magmatique. 

## Coposition
Pyroxène XY(SiO3)2
(XY) Sont des cations. (ions ayant perdu des électrons)

## Condition
Presence de Silicium 
Presence d'Oxygene
