# Plaine de Nickel d'aluminium

## Description

Mélange de nickel et d'aluminium naturellement gris.

## Composition

Nickel + Aluminium (Ni, Al)

## Condition

- Nickel
- Aluminium

## Illustration

![Nickel aluminium](/img/biome/nickel_aluminium_plain.jpg)

## Composants

### Plaine d'aluminure de nickel

#### Description

L'aluminure de nickel, sans oxygène, est blanc argenté avec des reflets bleus. Il forme des rochers chaotiques et accidentés d'une grande résistance.

#### Composition

Nickel + Aluminium (NiAl)

#### Condition

- Présence de nickel
- Présence d'aluminium

#### Illustration

![Aluminium Nickel](/img/biome/nickel_aluminium_equimolaire.png)

### Plaine de nickel 3 d'aluminium

#### Description

Le nickel 3 d'aluminium est de couleur bronze. Il forme des rochers chaotiques et accidentés de forme cubique.

#### Composition

Nickel 3 + Aluminium (Ni₃Al)

#### Condition

- Présence de nickel
- Présence d'aluminium

#### Illustration

![Nickel Aluminium3 real](/img/biome/nickel3_aluminium_real.png)
![Nickel Aluminium3](/img/biome/nickel3_aluminium_stylisee.png)

### Plaine de nickel d'aluminium 3

#### Description

Le nickel d'aluminium 3, sans oxygène, est blanc argenté avec des reflets bleus. Il forme des rochers très fragiles, chaotiques et accidentés.

#### Composition

Nickel + Aluminium 3 (NiAl₃)

#### Condition

- Présence de nickel
- Présence d'aluminium

#### Illustration

![Nickel Aluminium3](/img/biome/nickel_aluminium3.png)

### Plaine de nickel et d'aluminium

#### Description

La différence entre le point de fusion de l'aluminium (660 °C) et celui du nickel (1455 °C) provoque une solidification dissociée.

#### Composition

Nickel + Aluminium (Ni, Al)

#### Condition

- Présence de nickel
- Présence d'aluminium
