# Plaine de Nickel d'aluminium

## Description
Mélange de nickel d'aluminium n'aturellement gris. 

## Coposition
Nickel + Aluminium (Ni, Al)

## Condition
Nickel 
Aluminium

## Composants

### Plaine d'aluminure de nickel

## Description
Le nickel d'aluminium est sans oxygene est blanc argenté avec des refléts bleu.
Il forme des rochers chaotique et acidenté d'une grande resistance. 
 

## Composition
Nickel + Aluminium (NiAl)

## Condition
Presence de Nickel
Presence de Aluminium

## Illustration
![Aluminium Nickel](/img/biome/nickel_aluminium_equimolaire.png)

### Plaine de nickel 3 d'aluminium

## Description
Le nickel 3 d'aluminium est de couleur bronze.
Il forme des rochers chaotique et acidenté de forme cubique. 
 

## Composition
Nickel 3 + Aluminium (Ni3Al)

## Condition
Presence de Nickel
Presence de Aluminium
