# Talc plain folié

## Description
Le paysage de talc est blanchatre très claire. La texture est poudreuse.

## Coposition
Talc phyllosilicate (Mg3Si4O10(OH)2)

## Condition
Presence de Magnésium (Mg).
Presence de Silicium (Si).
Presence d'oxygène (O).
Presence d'eau (H2O).
