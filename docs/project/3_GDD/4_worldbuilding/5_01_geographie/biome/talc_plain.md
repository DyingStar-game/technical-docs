# Talc plain folié

## Description

Le paysage de talc est blanchâtre, très clair. La texture est poudreuse.

## Composition

Talc phyllosilicate (Mg₃Si₄O₁₀(OH)₂)

## Condition

- Présence de magnésium (Mg)
- Présence de silicium (Si)
- Présence d'oxygène (O)
- Présence d'eau (H₂O)
