# Plaine de Nitinol

## Description
Plaines constituées de Nitinol, est un alliage de Nickel et de Titane offrant une mémoire de forme et une hyper-élasticité.


## Composition
Nickel + Titane (Ni, Cu)

## Condition
Nickel : 50% 
Titane : 50%
