# Sol d'olivine

## Description

L'olivine est un minéral magmatique commun (il comprend plusieurs minéraux comme la fayalite).

## Composition

Forstérite et fayalite ((Mg,Fe)₂SiO₄)

## Condition

- Silicium (Si)
- Fer (Fe)
- Oxygène (O)
- Magnésium (Mg)
