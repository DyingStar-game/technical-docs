# Lac de lave

## Description
Dépression remplie de magma liquide, maintenu en fusion par convection thermique. Une croûte semi-solide peut se former en surface, constamment fracturée par les courants magmatiques


## Lac de lave de Corindon Caméléon Laiteux 

### Description
Le Corindon Caméléon contient des impureté de vanadium qui absorbe la lumiere jaune. Le Chrome renforce ce changement.
Ce qui provoque un changement de couleur. Le jour la couleur de la pierre est bleu-vert. La nuit Pourpre.

### Coposition
Coridon Caméléon (Al2-x-yCrxVy)O3
