# Moteur T1

Le moteur T1 permet de déplacer un petit véhicule.
Pour le MVP, le moteur a besoin juste besoin d'énergie électrique pour fonctionner.

Le composant est de taille 1, il est donc changeable à la main.
Il faut éteindre le véhicule pour retirer le moteur T1 d'une baie à composant.

## Caractéristiques
- Pélec	= 100,00 kW
- Couple = 600,00 Nm
- Favancement = 2000 N
- vitesse max à vide sur du plat = 103 km/h

Le nombre de moteurs ne change pas la vitesse max mais augmente l'accélération et le pente possible.
